# Document Watcher

## Overview
A Bash-based document automation tool that monitors an incoming directory, categorizes files, archives processed files, and maintains operational logs.

## Features
- Folder validation
- File counting
- File categorization
- Automated archiving
- Logging
- Log inspection using grep
