# 📄 Document Watcher

A production-oriented Bash automation project built while learning DevOps from first principles.

---

## Overview

Document Watcher monitors an incoming directory, validates its contents, categorizes files, archives processed documents, and generates operational logs.

The objective of this project is to evolve from a simple Bash script into a production-ready automation platform using Python, Docker, CI/CD, AWS, Terraform, Kubernetes and monitoring.

---

## Features

- ✅ Folder validation
- ✅ PDF, PNG and TXT file counting
- ✅ Automated archiving
- ✅ Operational logging
- ✅ Log inspection using grep
- ✅ Modular Bash scripting
